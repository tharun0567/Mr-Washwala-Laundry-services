# Mr. WashWala - Premium Laundry Services

Mr. WashWala is a modern, responsive web application for a premium laundry and dry cleaning service. Built with React and Vite, it offers an intuitive user interface for customers to browse services, select items, and schedule pickups.

## 🌟 Features

- **Dynamic Service Selection**: Easily browse and select from a variety of services including Dry Wash, Premium Wash, Laundry, and Shoe Cleaning.
- **Detailed Categorization**: Services are broken down into specific categories (Men's Wear, Women's Wear, Blankets, etc.) with transparent pricing.
- **Interactive UI**: Smooth animations and transitions powered by Framer Motion.
- **Cart & Checkout System**: Seamlessly add items to the cart, apply promo codes, and schedule pickup/delivery times.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices using Tailwind CSS.

## 🚀 Technologies Used

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **QR Codes**: qrcode.react

## 🛠️ Getting Started

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository:
   git clone https://github.com/tharun0567/Mr-Washwala-Laundry-services.git

2. Navigate to the project directory:
   cd Mr-Washwala-Laundry-services

3. Install the dependencies:
   npm install

### Running the Development Server
To start the development server, run:
npm run dev

The application will be available at http://localhost:5173 

### Building for Production
To build the app for production, run:
npm run build

This will generate a `dist` folder with the optimized production build.
